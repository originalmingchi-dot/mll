# 맑은농장 광고운영 제안서

## GitHub Pages 배포
1. 압축을 풀고 `index.html`과 `assets` 폴더를 함께 저장합니다.
2. GitHub 저장소의 최상위 경로(root)에 `index.html`과 `assets/linkprice-logo.png`를 업로드합니다.
3. 저장소의 **Settings → Pages**로 이동합니다.
4. Build and deployment에서 **Deploy from a branch**를 선택합니다.
5. Branch는 `main`, 폴더는 `/(root)`로 선택하고 Save를 누릅니다.
6. 배포가 완료되면 Pages 화면에 표시되는 URL로 제안서를 확인합니다.

## 조작
- 화면 아래 화살표 버튼으로 페이지 이동
- 키보드 ← / → 키로 페이지 이동
- 모바일에서는 좌우 스와이프로 이동

## 수정 안내
- 문구 수정: `index.html`
- 로고 교체: `assets/linkprice-logo.png` (파일명을 유지하면 됩니다.)
- 레퍼런스 수치는 제공받은 자료를 반영했습니다. 실제 게시 전 비교 기간, 전환 기여 기간, VAT 포함 여부 등을 확인하세요.
- 본 자료는 브랜드스토어 전환이나 광고 성과를 보장하지 않습니다.
